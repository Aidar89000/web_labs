# Лабораторная работа №3

Простое веб-приложение на **React** (Vite).
Данные берутся из бесплатного API [JSONPlaceholder](https://jsonplaceholder.typicode.com/).
Приложение повторяет лабораторную №2, но интерфейс теперь собран из React-компонентов.

## Что делает приложение

1. При открытии страницы загружает список постов — `GET /posts?_limit=10`.
2. Форма сверху добавляет новый пост — `POST /posts`.
3. Кнопка «Удалить» в карточке удаляет пост — `DELETE /posts/{id}`.

## Что нового по сравнению с lab2

| lab2 (JS + Ajax)                         | lab3 (React)                                   |
|------------------------------------------|------------------------------------------------|
| `document.getElementById`, `innerHTML`   | JSX: разметка описывается в коде компонента    |
| список обновляем руками (`append`, `remove`) | список — это состояние `posts`, React сам перерисовывает DOM |
| `XMLHttpRequest` + callback              | `fetch` + `async/await`                        |
| `form.reset()`                           | управляемые поля формы (`value` + `onChange`)  |

Заодно React экранирует текст постов, поэтому вставка `<script>` в заголовок
не сработает (в lab2 через `innerHTML` это было возможно).

## Запуск

Нужен установленный [Node.js](https://nodejs.org/) (18+).

```bash
cd lab3
npm install
npm run dev
# откройте адрес, который покажет Vite (обычно http://localhost:5173)
```

Сборка для публикации: `npm run build` (результат — папка `dist/`).

## Методы API

| Метод  | Адрес                | Что делает            |
|--------|----------------------|-----------------------|
| GET    | `/posts?_limit=10`   | Список постов         |
| POST   | `/posts`             | Создание поста        |
| DELETE | `/posts/{id}`        | Удаление поста        |

> JSONPlaceholder — учебное API: он отвечает так, будто пост сохранён,
> но на самом деле данные не хранятся на сервере. На каждый `POST` он
> возвращает `id = 101`, поэтому в списке у постов есть свой ключ `key`.
