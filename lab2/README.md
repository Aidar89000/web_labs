# Лабораторная работа №2

Простое веб-приложение на **HTML5 + CSS3 + JavaScript (Ajax)**.
Данные берутся из бесплатного API [JSONPlaceholder](https://jsonplaceholder.typicode.com/).

## Что делает приложение

1. При открытии страницы загружает список постов — `GET /posts?_limit=10`.
2. Форма сверху добавляет новый пост — `POST /posts`.
3. Кнопка «Удалить» в карточке удаляет пост — `DELETE /posts/{id}`.

Все запросы идут через `XMLHttpRequest` (классический Ajax), без библиотек и сборки.
В коде используются только `let`/`const` и стрелочные функции.

## Файлы

```
lab2/
├── index.html     # разметка страницы: форма, статус, список
├── css/style.css  # простые стили
└── js/app.js      # Ajax-запросы и вывод постов на страницу
```

## Запуск

Просто откройте `index.html` в браузере.
Если браузер блокирует запросы из файла, запустите статический сервер:

```bash
cd lab2
python -m http.server 8080
# откройте http://localhost:8080
```

## Методы API

| Метод  | Адрес                | Что делает            |
|--------|----------------------|-----------------------|
| GET    | `/posts?_limit=10`   | Список постов         |
| POST   | `/posts`             | Создание поста        |
| DELETE | `/posts/{id}`        | Удаление поста        |

> JSONPlaceholder — учебное API: он отвечает так, будто пост сохранён,
> но на самом деле данные не хранятся на сервере.
