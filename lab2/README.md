# Лабораторная работа №2

Веб-приложение на **HTML5 + CSS3 + JavaScript (Ajax/XHR)** с использованием свободного API [JSONPlaceholder](https://jsonplaceholder.typicode.com/).

## Возможности

- **Посты** — загрузка через `GET /posts`, поиск по заголовку и тексту, просмотр комментариев (`GET /posts/{id}/comments`), создание (`POST /posts`), редактирование (`PUT /posts/{id}`), удаление (`DELETE /posts/{id}`).
- **Пользователи** — загрузка через `GET /users`, карточки с контактами и компанией, кнопка «Написать пост» подставляет автора в форму.
- **Задачи (todos)** — загрузка через `GET /todos`, фильтры «Все / Выполненные / Активные», переключение статуса через `PATCH /todos/{id}`, поиск по названию.

## Технологии

- HTML5 (семантическая разметка, ARIA-атрибуты)
- CSS3 (переменные, grid/flexbox, адаптивность, анимации)
- JavaScript (ES6+, без библиотек и сборки)
- Ajax — классический `XMLHttpRequest` с Promise-обёрткой
- Делегирование событий, модальные окна, экранирование HTML (XSS-safe)

## Запуск

Приложение — статические файлы, достаточно открыть `index.html` в браузере.
Если браузер блокирует запросы с `file://`, запустите любой статический сервер, например:

```bash
cd lab2
python -m http.server 8080
# затем откройте http://localhost:8080
```

## Используемые методы API

| Метод   | Endpoint                  | Назначение                     |
|---------|---------------------------|--------------------------------|
| GET     | `/posts?_limit=18`        | Список постов                  |
| GET     | `/users`                  | Список пользователей           |
| GET     | `/todos?_limit=20`        | Список задач                   |
| GET     | `/posts/{id}`             | Один пост                      |
| GET     | `/posts/{id}/comments`    | Комментарии поста              |
| POST    | `/posts`                  | Создание поста (id: 101)       |
| PUT     | `/posts/{id}`             | Редактирование поста           |
| PATCH   | `/todos/{id}`             | Переключение выполнения задачи |
| DELETE  | `/posts/{id}`             | Удаление поста                 |
